# Ya Tersiyse? yayın kuyruğu

Zamanlanmış videolar yayımlanana kadar Releases altında durur, yayından sonra silinir.

## Yayın sırası
`yayin/queue.json` içindeki Instagram paylaşımları, saati gelince GitHub Actions (`yayin-sirasi`, 5 dakikada bir) tarafından Composio üzerinden yayınlanır. Saatler Türkiye saatidir.
